01

平台获取的数据范畴 Scope of Data Collected by the Platform

我们将以“最小化必要”为原则，收集维持服务正常运转所需的基础信息。 Based on the principle of "data minimization", we will collect the basic information necessary to maintain the normal operation of our services.

由您直接提交的资料 Information Submitted Directly by You

身份凭证： Identity Credentials: 当您注册时，我们需要获取您的电子邮箱以及您设置的密码（平台无法知晓明文）。若您选择通过 GitHub、Discord 等第三方生态快捷登录，我们将获取该平台的标准授权确认信息。 When you register, we need your email address and the password you set (the platform cannot access the plaintext). If you choose to log in via third-party ecosystems like GitHub or Discord, we will obtain standard authorization confirmation from that platform.

交易核对信息： Transaction Verification Info: 在您为账户充值时，我们会记录生成的内部订单号及到账状态，以便为您准确计算可用额度和处理账务问题。 When topping up your account, we record the generated internal order numbers and payment statuses to accurately calculate your available quota and process billing issues.

系统运行中自动产生的数据 Data Automatically Generated During System Operation

通信与设备特征： Communication & Device Features: 为确保界面的最佳渲染效果及防范异常登录，我们会捕捉您的 IP 地址、操作系统版本、浏览器类型及界面语言偏好。 To ensure the best rendering effect of the interface and prevent abnormal logins, we capture your IP address, OS version, browser type, and UI language preference.

API 调度轨迹： API Call Trajectories: 平台系统会客观记录您的调用行为元数据，包括但不限于请求发生的时间戳、目标模型名称、Token 的消耗数值以及服务器响应状态码。这些数据是为您提供透明账单和排查技术故障的核心依据。 The platform system objectively records the metadata of your call behavior, including but not limited to the request timestamp, target model name, Token consumption, and server response status code. This data is the core basis for providing transparent billing and troubleshooting technical faults.

特别承诺：我们绝对不触碰的数据 Special Commitment: Data We Absolutely Do Not Touch

本平台扮演纯粹的“数据传输通道”角色。您向大语言模型发送的任何提示词（Prompt）文本，以及模型生成并返回给您的所有内容（Completion），仅仅在我们的中转内存中短暂经过。平台绝不进行任何形式的日志留存、缓存或持久化记录。 This platform acts purely as a "data transmission channel". Any prompt text you send to the large language model, and all completion content generated and returned to you by the model, only briefly pass through our transit memory. The platform never conducts any form of log retention, caching, or persistent recording.
